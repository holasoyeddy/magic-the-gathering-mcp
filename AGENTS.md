## Agent skills

### Issue tracker

Issues and specs are tracked as local Markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the default five-role label vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

Domain documentation uses a single-context layout. See `docs/agents/domain.md`.

### Coding standards

Code changes and reviews must follow `CODING-STANDARDS.md`, with human readability as the primary design constraint.

### Delivery

Implementation tickets ship as one ticket per branch and one pull request per ticket. See `docs/agents/delivery.md` before planning or implementing ticketed work.
